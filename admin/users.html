Needs an API

The data schema (§5.6) defines a users table — name, email, role, is_active, last_login_at, mfa_enabled — and the permission matrix (§3) makes system_admin the only role that should reach this screen. But §7.4 (API Contract — Admin) doesn't list a CRUD endpoint for it, only GET /v1/admin/audit-log. Give me something like CRUD /v1/admin/users (plus an invite/resend-invite action) and this wires up exactly like Manufacturers — note in the spec: "Changing a role takes effect on the user's next request, not their next login", so the update endpoint needs to invalidate any cached authorisation immediately.
